# История изменений — MedDial

## 10.07.2026
- В ссылку добавлена передача ФИО (`?to=...`). Программа склоняет имя в дательный
  падеж и показывает в уведомлении: «Звоню Иванову Ивану Ивановичу».
- Модем кладёт трубку сразу по завершении набора, а не держит линию — чтобы не
  создавать помех разговору.

## 09.07.2026
Первый рабочий звонок на боевом оборудовании. Уточнена схема подключения: телефон
подключается к линии параллельно модему (через тройник), гнездо `Phone` модема не
используется. Окно на снятие трубки увеличено.

## 06.07.2026
- Один и тот же скрипт работает и на Windows, и на Linux.
- На Linux программа работает **без** `pyserial` — открывает модем напрямую через
  стандартную библиотеку (важно для машин без доступа к репозиториям).
- Добавлен слепой набор `ATX3` — набор без ожидания городского гудка, для офисных АТС.
- Подробный журнал набора в `meddial.log`.

## 31.05.2026
Начальная версия. Клик по номеру `meddial:<номер>` на веб-странице набирается на
настольном телефоне через USB-модем по обычной аналоговой линии. Обработчик протокола
регистрируется в системе (реестр Windows / xdg на Linux). Тестовый режим `DRY_RUN`.
