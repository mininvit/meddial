# MedDial

**Разработчик:** [@mininvit](https://github.com/mininvit) · проект «Цифровой пост»

**Клик по номеру на странице — и настольный телефон сам набирает.**

На посту звонят с обычного телефона, и набирать номер руками каждый раз неудобно.
MedDial это убирает: кликнул по номеру на странице — он уходит в небольшую программу
на компьютере, та диктует его USB-модему, и модем набирает по обычной телефонной линии.
Ни интернета, ни SIP, ни облачной АТС не нужно: звонок идёт по той же связи, что и всегда.

---

## Как это работает

```
[ Веб-страница ]                     [ Компьютер ]                 [ Телефон ]
 клик по номеру                                                   аналоговый аппарат
      │                                                                 │
      │  ссылка meddial:<номер>?to=<ФИО>                                │
      ▼                                                                 │
[ обработчик протокола ОС ]  ──►  [ программа набора ]  ──USB──►  [ USB-модем ]
   (реестр / xdg)                   разбор + набор                ATDT<номер>
                                                                    │
                                                          ┌─────────┴─────────┐
                                                          │  аналоговая линия  │◄── телефон
                                                          └────────────────────┘   (параллельно)
```

1. На странице номер оформлен ссылкой вида `meddial:89601225178?to=Иванов Иван Иванович`.
2. Клик передаёт ссылку зарегистрированному обработчику протокола `meddial:` в системе.
3. Программа вынимает из ссылки номер и имя, открывает модем и отдаёт ему команду
   тонового набора.
4. Модем снимает линию и набирает; оператор поднимает трубку параллельного телефона —
   разговор остаётся на ней. Модем сразу освобождает линию.

Имя из ссылки склоняется в дательный падеж и показывается в уведомлении:
«Звоню Иванову Ивану Ивановичу».

## Устройство

Работает через **аналоговый USB-модем** (USB fax/voice modem, V.92) — коробочка, которая
с одной стороны включается в телефонную линию (RJ11), с другой в USB компьютера.

- Проверенная модель: **Conexant USB CX93010 ACF Modem** (типовой USB-факс-модем на чипе
  Conexant). Подойдёт любой аналоговый USB-модем с поддержкой AT-команд.
- В системе виден как последовательный порт: `COM3` (Windows) или `/dev/ttyACM0` (Linux).
- Питание от USB, отдельный блок не нужен.

### Подключение

Телефон должен висеть на линии **параллельно** модему, а не через него — иначе отбой
модема будет рвать разговор:

```
[ Розетка ]──► [ Тройник RJ11 ]──┬──► [ гнездо Line модема ]
                                 └──► [ Телефон ]
```

Гнездо `Phone` на модеме не используется. Порядок работы: **снять трубку → кликнуть по
номеру → говорить.**

## Возможности

- Набор номера по клику на веб-странице.
- Голосовой набор по фамилии.
- Склонение ФИО в дательный падеж для уведомления.
- Слепой набор — не ждёт городского гудка, работает и через офисную АТС.
- Работает и на Windows, и на Linux.
- Журнал набора и тестовый режим без реального звонка.

## Установка

**Linux (в т.ч. RED OS):**
```sh
cd meddial
sh install.sh
sudo usermod -aG dialout $USER    # доступ к модему; затем перезайти в систему
```

**Windows:**
```powershell
powershell -ExecutionPolicy Bypass -File install_windows.ps1
```
Нужен Python с python.org (галочка «Add to PATH»).

При первом клике браузер спросит, чем открыть ссылку `meddial:` — выбрать MedDial и
отметить «запомнить».

> Определитесь с постоянным местом папки и запустите установку один раз оттуда.
> Обработчик прописывает абсолютный путь — после перемещения папки его нужно ставить заново.

## Настройка

Основные параметры: путь к модему (если не определился сам), цифра выхода на город через
корпусную АТС, время ожидания набора и тестовый режим без реального звонка.

---

## Диагностика

Каждый клик пишется в журнал рядом с программой: что пришло, какой номер и кому, какие
команды ушли модему и что он ответил.

- `устройства: нет` — модем не виден (USB / права доступа).
- `NO DIALTONE` при подключённой линии — нужен выход на город (префикс).
